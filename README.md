# 🛡️ PassiveRecon-AI

Automated Passive Information Gathering & Pre-engagement tool powered by AI.

## 🚀 Features
- **Passive Subdomain Enumeration:** Using `crt.sh` (SSL Certificates).
- **DNS Analysis:** Resolving A, MX, NS, and TXT records.
- **Wayback Machine Integration:** Fetching historical URLs.
- **AI-Powered Analysis:** Uses OpenAI to generate a pre-engagement report and suggest attack vectors.

## 🛠️ Tech Stack
- Python 3
- Streamlit (UI)
- OpenAI API
- Requests & dnspython
